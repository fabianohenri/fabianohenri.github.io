ClipsVirais

Política de Privacidade

Última atualização: 16 de setembro de 2026 Contato: fabiano.oliveira@projetusti.com.br
Em resumo: o ClipsVirais processa vídeo e áudio localmente, na máquina do operador. Não há coleta de dados de terceiros, não há banco de usuários e a única integração externa é a API oficial do TikTok, usada apenas para publicar vídeos na conta que o próprio operador autorizou.

01 Quem opera esta ferramenta

O ClipsVirais é operado individualmente por Fabiano Oliveira, para uso pessoal. Não é um serviço multiusuário nem coleta dados de visitantes de um site — é um programa executado localmente por quem o instala.

02 Dados processados

DadoOrigemOnde fica
Arquivos de vídeo originais Fornecidos pelo próprio operador Somente no disco local do operador
Transcrição de áudio Gerada localmente por modelo de reconhecimento de fala rodando na própria máquina Somente no disco local do operador
Token de acesso do TikTok Emitido pelo TikTok após autorização OAuth do operador Arquivo de configuração local, não versionado nem compartilhado

03 Uso da API do TikTok

A integração com o TikTok usa a Content Posting API oficial. O escopo solicitado permite apenas o envio (upload) de vídeos para a conta que autorizou o aplicativo — a ferramenta não lê, não coleta e não armazena dados de perfil, seguidores ou conteúdo de outras contas do TikTok.

04 Compartilhamento com terceiros

Nenhum dado é vendido, alugado ou compartilhado com terceiros. O único destino externo dos vídeos gerados é a própria conta do TikTok autorizada pelo operador, através da API oficial da plataforma.

05 Retenção e exclusão

Vídeos, transcrições e tokens ficam armazenados apenas localmente, sob controle do operador, que pode apagá-los a qualquer momento removendo os arquivos correspondentes. Revogar a autorização diretamente nas configurações da conta do TikTok invalida o token de acesso.

06 Alterações nesta política

Esta política pode ser atualizada para refletir mudanças na ferramenta. A data no topo desta página indica a versão vigente.
